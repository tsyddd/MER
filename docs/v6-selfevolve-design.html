二、流程图

总览

图 1　共同骨架与两种自进化的挂载点。主流程（橙）对两个方法完全相同：三专家 → 一致则直接输出 → 否则辩论 2 轮 → 汇总器。R²-MAD 只改两轮辩论（给每位专家带上检索到的经验和同伴可靠度），不动专家和汇总器；SkillOpt 改全部四个模块（给每个角色的 system prompt 加一份训练出来的技能文档），不检索。

R²-MAD

图 2　R²-MAD 训练集怎么来。候选池 3,377 条 → 补图谱 → Gemini、GPT 各跑三专家第 0 轮 → 按第 0 轮路由留下不一致样本 → 超过上限就分层抽样 → 对留下的样本做 Caption 合成 Q → 得到每个模型自己的训练集 T（≤ 400 条）。

图 3　用训练集 T 建库：一个训练样本产生哪些记录。复用第 0 轮，再强制跑满 2 轮辩论（不用经验），中间各生成一次摘要和共识率；每位专家每轮写一条记录，键由“题目 + 自己上一轮输出 + 上一轮摘要”拼成，值由“题目 + 标准标签 + 本轮输出 + 是否改立场 + 对错”拼成。

图 5　一位专家在一轮里做的四步。②③是 R²-MAD 的两个贡献：“辩论状态感知的检索”（共识越高越偏多样）和“用历史经验估计同伴是否可信”。

图 6　检索结果怎么进到提示词里。在 v4 辩论提示词的 JSON 上只增加两处：案例块和同伴可靠度标注，其余全部沿用。

图 7　SkillOpt 阶段一：训练一个专家的循环。目标模型不动，只改一份 Markdown 技能文档；每次修改要过验证集门控。三位专家各自独立训练。

图 9　SkillOpt 阶段二：冻结专家后，依次训练辩论 1、辩论 2、汇总器。每一段的循环和图 7、图 8 相同，只是被训练的角色、得分不同；上游已训练好的技能被冻结。

二·补　R²-MAD 的检索键与值（逐字段，来自原版源码 memory_utils.py、agent.py，换成我们的数据）

每条记录对应（一条训练样本 s，一位专家 e，一轮 r ∈ {0,1,2}）。Q = Gemini 一次综合 Caption + 情感识别问题（含该数据集标签集）。

部分内容用在哪
键 K(s,e,r)Q
+ 专家 e 第 r−1 轮的回答（r = 0 时没有）
+ 第 r−1 轮的辩论摘要（r = 0 时没有）
三者拼成一段文本，用 embedding 模型编码。键描述的是“专家 e 在作第 r 轮回答之前的状态”。		测试时第 t 轮，用当前的 Q + 专家 e 第 t−1 轮回答 + 第 t−1 轮摘要编码成查询向量，和库里同一位专家的键算余弦相似度。
值 V(s,e,r)① 题目 Q
② 标准标签（原版是完整标准解答，我们只有标签）
③ 专家 e 第 r 轮的完整回答（答案 + 理由 + 证据）
④ 这一轮有没有改变立场（r = 0 为 N/A）
⑤ 这一轮的回答是对还是错		取回后原样放进提示词的 <examples> 块。含义是“在类似的状态下，专家后来是这样答的，结果是对 / 错”。
元数据专家、轮次 r、上一轮共识率（三人里最多的同标签人数 / 3：1/3、2/3 或 1）、本轮是否答对、最终是否答对（、数据集）过滤（只取同一位专家；我们再加：只取同一个数据集）；MMR 里的 r(case) = 本轮是否答对；同伴可靠度里的“当时是否答对”。
回答库键 = (样本, 轮次, 专家) 的编号；向量 = 该专家该轮回答的 embedding估计同伴可靠度：对每个候选案例，取该案例里另外两位专家在第 r−1 轮的回答向量，和现在同伴的回答比相似度。
读源码得到的三个细节
  • 检索时只按“专家”过滤，不限制轮次：测试第 1 轮的查询，也可能取到库里第 0 轮的条目（它们的键只有 Q，没有回答和摘要，相似度通常更低）。
  • “题目”在键和值里都出现：键里的 Q 决定“像不像”，值里的 Q 让模型看到那个案例在说什么。因为我们的 Q 含一段综合 Caption，一条案例会较长；每位专家带 n 条案例，n 越大提示词越长。
  • 值里的证据引用的是那条训练样本自己的帧编号和时间，当前样本没有这些帧；只能把它当作“答案与理由的写法”参考，这是视频任务和原版文本任务的差别。

三、数据与评价

用途样本说明
训练（R²-MAD）3,377 条里的不一致样本建经验库。每个模型各自的不一致样本，上限 400 条；比例未知，要跑完第 0 轮才知道（旧 400 条是按“≥3 模型答对”筛的偏容易，约 15%，整体池预计更高，很可能触到上限）。
训练（SkillOpt）新 400 条rollout 与反思。标签只在训练里用。
验证（门控）新 60 条SkillOpt 每次修改的接受 / 拒绝；R²-MAD 默认不用验证集，超参取论文默认值。
测试旧 400 条SkillOpt：全部 400 条（受训专家改变分支）；R²-MAD：其中不一致的 117 条（Gemini 62 + GPT 55），可直接和 v4 / Direct / v5 对比。
  • 对照：Direct 单次均值 60.4（Gemini 36.6 + GPT 23.8）、Direct 三次投票 61.8、v4 辩论 45、v5 最好的 E（63）。
  • “有提升”的标准沿用：不一致 117 条合并后比 Direct 均值多至少 4 条，且两个模型各自不低于自己的均值；SkillOpt 另报全 400 条合并后的总数。
  • 必须报告：每个阶段后的准确率（专家 R0、辩论 1、辩论 2、最终）、被改答案数及改对 / 改错、路由后不一致样本数的变化、调用数。
  • 噪声：Direct 单次运行波动 6 条，门控又只有 60 条验证样本，所以任何 1–3 条的差别都不解读。
