分歧样本上 Debate 是否不如 Direct：文献调研

调研日期 2026-11-04。检索了 arXiv 与搜索摘要；标注“仅摘要”的论文没有读全文，数字未核对。本页只是文献结论，不是我们数据的结论；我们自己的数据见末节。

结论先行

没有找到一篇论文，直接把“只在专家分歧（不一致）子集上，Debate 的准确率低于 Direct”作为主要结果报告。我能找到的是三类相关证据：

  1. 整体上 Debate 不优于单次回答或多数投票（最多证据）：如 2502.08788、2508.17536、2510.20963。这些是全集平均，不是分歧子集。
  2. 机制上，分歧会被“共识化”压掉（与你的观察最接近）：2609.38324 认为，当 agent 不表达异议时，讨论可能把错误的初始多数固化为错误共识；2510.20963 认为，追求共识的辩论会“过滤掉有信息量的分歧”。
  3. 有一篇反向证据（2605.09618）：分歧高时辩论带偏的情况更少；辩论有益的样本里，多数出现在投票分裂或少数一致（H≤1）时，而不是全票一致且错误（约 36%，见下文修正）。这与“分歧子集上 Debate 更差”的直觉不一致，需要认真对待。

Stop Overvaluing Multi-Agent Debate（arXiv 2502.08788，2025）
仅摘要		 整体，未专门分析分歧 5 种 MAD、9 个基准、4 个模型；MAD 常常打不过 CoT 和 Self-Consistency，且计算量更大。中（全集）
Debate or Vote（arXiv 2508.17536，NeurIPS 2025 Spotlight）
仅摘要		 整体；理论上把辩论建模为鞅 “辩论本身不提高期望正确率”；多数投票解释了大部分归因于辩论的收益。中（全集，理论支持）
When and Why Does Multi-Agent Debate Fail（arXiv 2510.20963）
仅摘要		 有：分析“信息性分歧”如何被过滤 普通辩论可能显著低于单 agent；追求共识的 CosMAD “过滤掉有信息量的分歧，换来过早共识”；竞争式 CopMAD 变成“廉价谈话”。提出的 ColMAD 在同等预算下胜过单 agent。中（机制性，数字未核）
Multi-agent discussion gains less when dissent is withheld（arXiv 2609.38324，2026-09）
仅摘要，新论文		 最直接相关：分歧样本的建模 只有当“压制异议率” c 低于临界值 c* = γ/(γ+a) 时，讨论才能推翻错误的初始多数；否则会以错误共识告终。不要求异议的提示能提高收益；关闭推理也能提高收益。中（理论+估计，数字未核）
Talk Isn't Always Cheap（arXiv 2509.05396）
仅摘要		 整体；强调“正确变错误” 模型常因同伴推理而把正确答案改成错误答案，偏向一致而不是挑战错误推理；弱 agent 加入强 agent 的讨论时，结果可能更差。中（失效模式）
Statistical Scouting Finds Debate-Safe but Not Debate-Useful Cases（arXiv 2605.09618，2026-05）
读了摘要与结果段		 相反的证据：按投票熵分层 对比 greedy（直接）、三次投票、两 agent 批评式辩论（同 960 token 上限）。投票熵高时辩论的“反噬”明显减少；47 个辩论有益的样本中，31 个（66%）属于 H≤1（含分裂投票），其中全票一致且错误的只有 17 个（约 36%）。

仅摘要		 整体；提出“分歧崩溃” 谄媚会限制辩论效果；去中心化设置可能崩溃，且不稳定地优于单 agent。中（机制）

对我们问题的含义

  • “Debate 不如 Direct”本身有文献支撑，但主要是全集平均，不是分歧子集。直接说“分歧子集上 Debate 更差”，目前没有现成的论文直接报告。
  • 机制上最像我们的情况：2609.38324 和 2510.20963 认为，同模型或同质 agent 的讨论会把分歧压成共识，于是分歧样本上的辩论变成“在错误共识里收敛”。这与 F2、F5（同错、辩论后一致但答错）的观察吻合。
  • 需要注意的反例：2605.09618 发现，辩论的收益主要来自“投票一致但错误”的样本，分歧高时辩论反而更少带偏。这说明我们的分歧分支结论可能依赖数据和模型，不能直接外推。
  • 比较口径：文献多以“同等计算量”或“同等 token 上限”与单次回答 / 多数投票比较。我们的 F6 比较的是同一批样本上的 Direct 与 v4 辩论分支，口径需要说明。
