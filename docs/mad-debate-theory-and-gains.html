更正：上一版把 2605.09618 的“66% 辩论有益样本是投票一致且错误”写错了。全文表 2 与第 5.3 节：66%（31/47）属于 H≤1（含分裂投票），全票一致且错误的只有 17/47，约 36%。另外，上一版引用的 2601.19921 “confidence 加权辩论期望上优于多数投票”也过强：全文只证明信念在期望上单调上升（次鞅），优于多数投票是实验结论。

一、结论先行

  1. 理论上，普通辩论是“鞅”：在同质、全连接的模型里，辩论不改变期望正确率（2508.17536 Thm 2；2601.19921 Eq.14）。所以“辩论不优于多数投票”在理论上是默认结果，要超过它必须引入某种偏向正确信号的更新。
  2. 真正的理论是一个临界条件（2609.38324）：压制异议率 c 与“内化率 a”、“净纠正率 γ”之间有阈值 c* = γ/(γ+a)。c 高于 c* 时，讨论会以错误共识收敛。这是对分歧子集失败最直接的解释，但它是局部线性化，不是全局定理。
  3. 能超过多数投票的，全都是“改变更新规则”的做法，不是“多跑几轮”：
    • 2601.19921：多样化初始化（训练-free）+ 置信加权（需要 RL 训练 + 口头置信度）。
    • 2510.20963：异构辩手 + 非零和“协作”框架（只用提示词），但其理论保证只是“不差于单 agent”，不保证更好。
    • 2606.02866：代码执行 + 证据门控的批评者，在生成任务上是唯一显著超过单 agent 的（+5.3 pp），纯文本辩论反而更差。
    • 2609.38324：不要压制异议的指令、关闭推理（降低内化 a），能提高增益。
  4. 没有一篇论文在“分歧子集”上单独报告 Debate 超过 Direct。所有“超过”的结果都是全集平均，且多数只比多数投票或单次回答高 1–5 分。

二、逐篇：理论分析

论文模型与假设主要定理 / 命题我对它的评价
2609.38324 Multi-agent discussion gains less when dissent is withheld（2026-09） 均场模型。每个 agent 有二元私人信念 z 和公开陈述 y；看到 q 个邻居（q≥3 才出现阈值）。多数与自己信念一致则照说；否则以概率 c 压制异议并说多数，再以概率 a 内化。其余情况以 ρ·d（d=可见异议比例）重新考虑，以 r 正确。γ ≡ ρ(2r−1)。 线性化：Zt+1 = Λ(c) Zt，Λ(c)=1−c·a+(1−c)γ。少数派增长当且仅当 (1−c)γ > c·a；临界 c* = γ/(γ+a)（Eq.6）。a→0 则 c*→1。r>1/2 时全正确状态稳定。c*之上两个稳定态共存，由 p 决定去向；相变点数值计算，略早于 c*。 最接近我们的问题：分歧样本能否被救回，取决于“压制异议”与“内化”的比例。但它是一阶局部近似，且 ρd 这个“重新考虑”的假设无法从日志识别（原文 Discussion 承认）。
2601.19921 Demystifying Multi-Agent Debate: Confidence and Diversity（v3） Dirichlet–categorical 模型（Choi et al. 2025）。每个 agent 有 Dirichlet 参数，邻居计数直接加入。 无偏辩论 E[pt|F] = pt−1（鞅，Eq.14）。Prop.1 / Thm.2：若 P(AT|S=s) 随 s 单调不减，且多样化初始化一阶随机占优随机采样，则多样化初始化的正确率不低。Thm.1：置信加权使 E[pt|F] ≥ pt−1（次鞅），前提是置信度与正确性正相关（Assumption 1）。 “多样化”是有理论的，但理论只说先验变好，不说最终优于多数投票。置信加权的次鞅结论依赖“置信与正确性正相关”，这在未校准的口头置信度上不一定成立。
2508.17536 Debate or Vote（NeurIPS 2025 Spotlight） Dirichlet 信念 + 分类采样；同质、全连接（或孤立、同质小团）时成立。 Thm.1：多数投票成功概率 ≥ 1 − exp(−N(Δ/√K − 1/√N)²)（“放大效应”）。Thm.2：辩论为鞅。“偏向正确信号的更新”使辩论产生朝正确答案的漂移，但没有给出定理，只是定性论证。 理论上最干净。核心信息是：辩论本身不增加期望正确率，增益只能来自“修正偏置”。它也明确建议“先做好集成”。
2510.20963 When and Why Does Multi-Agent Debate Fail（v2） 博弈论：两个辩手 + 裁判；辩论有用当且仅当 I(Y;M|X₀)>0。 Prop.2.4：竞争式辩论（CopMAD）是零和“廉价谈话”，均衡为胡说，风险等于不辩论的贝叶斯风险。Prop.2.6：共识式（CosMAD）只保留一致部分，风险 ≥ 不辩论的风险，严格时分歧含信息。Prop.2.8：协作式（ColMAD）风险 Vcol ≤ R(X₀)，严格当 I(Y;Me|X₀)>0。Cor.2.9：Vcol ≤ Vcos ≤ R(X₀)=Vcop。 这是理论上唯一直接讨论“分歧信息是否被丢弃”的。但它的 Prop.2.8 只保证“不比单 agent 差”，不保证“更好”；作者自己也承认增益取决于消息的经验信息量。
2606.02866 When Helping Hurts（数据清洗，2026-06） 逐项判断：批评者修正一个值。pg=生成器对的概率，pc=批评者能识别错误的概率，pr=修正成功的概率。 Eq.1：辩论对一个条目有益当且仅当 (1−pg)·pc·pr > pg·(1−pc)，等价于赔率形式 pc/(1−pc)·pr > pg/(1−pg)。Eq.2：任务级 ΔPerf ≈ k·α·[…]·(1−ρβ)，ρ 为输出依赖度，β 为级联严重度。附录 L 的完整推导未读到。 这是最可操作的理论：它把辩论的收益拆成“救回”与“带偏”两项。但 pc、pr 是用准确率和人工估计的粗值，不是测量值。
2605.09618 Statistical Scouting（2026-05） 无形式化理论；投票熵分层的经验分析。 只有论断：熵只能预测辩论“安全”，不能预测辩论“有用”（结构性论断，靠经验，作者承认 N=300 限制了推广）。 作者自己的理论论断是“断言，不是证明”。

四、与我们问题（分歧分支）的关系

  • 分歧子集上，理论的关键量是“救回”和“带偏”。2606.02866 的条件可以直接套到我们的分歧分支：在三位专家不一致时，正确标签往往是少数派。辩论只有在“少数派被救回的概率 × 救回后正确”大于“多数派被带偏的概率”时才有收益。F6 里辩论分支的表现（v4 26/62 对，Direct 38/62 对）说明后一项很大。
  • 2609.38324 解释了为什么少数派救不回来：压制异议率 c 高，且内化率 a 高时，讨论以错误共识结束。同模型的三位专家（我们的 Gemini 与 GPT 各自的三个角色）很可能 c 高、a 高，所以 c* 很小。这是假设，需要用我们的辩论日志估计 c、a，目前未做。
  • 能直接在我们的任务上尝试、且不需训练和 logprob 的候选：(a) 指令“不要压制异议，哪怕与多数不同也要说出来”；(b) 辩论时关闭推理（只给答案 + 一句理由）；(c) 把“分歧”定义为“少数派的证据是否可检查”，只让可执行 / 可核对的证据进入辩论（对应 2606.02866 的证据门控）。这三个都是提示词级别的改动，但都需要新的模型调用，需先得到你的授权。
  • 不能直接搬的：2601.19921 的置信加权与 2510.20963 的异构辩手，前者需训练，后者需要两个不同模型家族；我们可以用三位不同的模态专家，但它们不是同一模型的独立采样，理论前提不同。
