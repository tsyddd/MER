v5 设计草案（简化版）：不一致分支改成“候选内对比裁决”

日期 2026-11-03。待你审核；尚未实现、未运行，没有任何结果。这一版只做一个改动，替换上一版的四步方案（那版的抽取论断、盲核对等因为太重、且每一步都没有数据支持，已放弃，见第六节）。下面的数字来自已保存的 v4 / Direct 结果（metrics/findings_log.md F5–F7）。

一、要解决的问题

  • 不一致分支是 v4 最弱的一块，而且是辩论造成的。400 条里有 117 条（Gemini 62、GPT 55）没有恰好 1 个共同标签。v4 辩论在这块答对 26 和 19 条，约等于在候选里随机选（期望 25.6 和 22.8）。
  • 辩论没有产生新信息。少数派专家几乎全部改投多数（13/13、6/7），而多数方只对 4/13 和 2/7；改答案时写的“核实”只是语言。
  • 没有专家参与的 Direct 在这块明显更好。Direct 答对 38 和 26 条，它的答案 96%–97% 落在专家候选内（60/62、53/55）。
  • 候选里有答案，选不出来。候选并集覆盖真实标签 89%–94%，完美选择的上限是 58 和 49 条。瓶颈是在 2–3 个候选里选对。

问题：在不一致分支里，一个只看原媒体、并被要求逐个比较候选标签证据的裁判，能不能比不加约束的 Direct 选得更准？

我的猜测（未验证）：Direct 的一部分错误是没有认真比较备选标签；强制“每个候选各给一条支持、一条反对”可以让它真的去对照媒体。同时放入情绪轮里已有的易混边界，是 Direct 没有的信息。

二、方法与流程图

只改黄色部分。前半（Round 0 → 反思 → 路由）和一致分支沿用 v4 已保存的输出，不重跑。裁判看不到任何专家的东西，所以没有“多数”可以跟；它也不是辩论，只有一次调用。

设计点选择为什么
候选标签用 v4 已经算出的候选并集（三位专家 Round 0 与反思后出现过的全部标签，含备选）覆盖 89%–94%，不需要另造候选；答案限制在候选内也让选择变成 2–3 选 1。
不给专家的任何内容不给答案、理由、身份、图谱、组织文本数据显示专家之间没有额外信息，给了反而会被带偏；Direct 正是因为独立才表现更好。
强制对比每个候选各一条支持、一条反对，带位置要求裁判真的在媒体里为每个候选找依据，而不是只给一个印象。
易混边界说明取情绪轮里已有的、同时提到至少两个候选标签的条目；没有匹配的条目就不放这是 Direct 没有、而我们已经写好的知识；规则简单，不为这 117 条定制。
调用次数每个不一致样本 1 次保持简单；117 次调用。

三、裁判的“问题”：提示词与输入输出草案（待审核）

系统提示词草案（正向写法，不含版本信息；“易混边界”处按上面的规则插入相应条目）：

你是情绪判别员。判断指定目标人物在当前片段的情绪。你有按时间排列的8帧、可用字幕，以及audio_provided=true时的真实音轨；没有音轨时，听觉判断限于字幕与视觉。
candidate_labels是这条样本的候选标签（2到3个），你的答案从其中选一个。
请逐个候选标签对照原始媒体：
1. 为每个候选找出原媒体里最能支持它的一条具体观察，和最能反对它的一条具体观察；每条都写明位置（frame编号与时间、音轨时间段或字幕原话）。
2. 先写看到或听到了什么，再写它说明什么；只使用片段里可以定位的观察。找不到时写“未找到”。
3. 比较各候选的支持与反对，选出证据最充分的一个。
【易混边界】（只放入与这几个候选相关的条目，条目取自本数据集情绪轮的易混边界说明）
……
只返回JSON，字段恰好为：{"comparison":[{"label":"候选标签","support":{"observation":"...","location":"..."},"against":{"observation":"...","location":"..."}}],"answer":"候选标签之一","reason":"2到3句：为什么选它，以及为什么不选其他候选"}。程序统一包装<answer>。

用户消息（输入）：

{"sample_id": "...", "target_speaker": "...", "candidate_labels": ["worried", "surprise"], "frame_times_seconds": [...], "audio_provided": true, "subtitle": "..."}
# 不包含：专家的答案/理由/证据、专家身份、图谱、组织文本、辩论记录、真实标签。图片为8帧，Gemini 另附音轨。

程序检查：JSON 字段齐全；answer 必须在 candidate_labels 内；comparison 覆盖每个候选；没有音轨时不得声称听过声音（与 v4 一致）。不合格时重试，最多 3 次；仍不合格则该样本记为无效并如实统计，不用其他方法补。温度 0，只跑一次。

四、评价指标与判断标准（先定好，再跑）

灰色=随机选的期望，橙=三位专家各自的 Round 0 主答案，蓝=v4 辩论，绿=Direct，粉=候选集上限（完美选择）；黄色虚线框是 v5 的位置（待运行）。柱长按各自分支的样本数缩放。三位专家取 Round 0 独立判断的主答案；反思后的主答案分别是 Gemini 25 / 31 / 26、GPT 30 / 16 / 19，几乎相同。每位专家只回答自己拿到的信息（图谱专家有图谱与组织文本，另两位没有）。

主要判断（运行前约定）

  • 对照组是 Direct，不是 v4：Direct 在这块已经比 v4 好很多。
  • 算“有提升”的条件：合并两个模型的 117 条，v5 比 Direct 多答对至少 4 条（约 3.4 个百分点），并且两个模型各自都不低于 Direct。否则结论是“没有提升”，不一致分支直接用 Direct 兜底。
  • 这个阈值是我定的，可以改；117 条的检测力很低，即使达标也只能说“值得在新样本上验证”，不能说方法有效。

每个模型都要报告的表

表内容
T1 分支准确率不一致分支答对数：v5 / 三位专家 / Direct / v4 / 随机期望 / 候选集上限；按模型、按数据集（MER2024、MELD）、按验证与训练拆开。
T2 与 Direct 的逐条翻转同对 / 同错 / v5 改对 / v5 改错，附精确符号检验的 p 值（仅供参考，样本很少）。
T3 整体 400 条“一致用 v4、不一致用 v5”的整体准确率，对照 v4（307 / 300）、Direct（311 / 294）、“一致用 v4、不一致用 Direct”（319 / 307）、上限（339 / 330）。
T4 约束与成本答案落在候选内的比例（应为 100%）、重试次数、无效样本数、调用次数和 token 数。
T5 人工抽查翻转的样本（改对和改错各至少 10 条，不足则全看）：检查“支持/反对”的观察是不是真的能在帧、字幕里定位。这是定性阅读，只作说明。

防止自欺的做法

  • 提示词在运行前冻结，不在这 117 条上调；跑一次，所有结果都报告。
  • 真实标签不进入任何调用，只在算分时读取。
  • 训练集样本是按模型正确性筛选的、验证集是开发复用数据，所以绝对数字只作参考，重点看相对 Direct 的差值。
  • 如果有提升，下一步是在没有被模型筛选过的新样本上确认，而不是继续在这 117 条上改。

五、风险与限制

  • Direct 的答案 96%–97% 已经在候选内，所以“限制在候选内”本身几乎没有区别，真正的变量是“强制对比”和“易混边界说明”。如果有提升，我分不清是哪一个起作用；需要的话可以再各去掉一个做消融，但那是第二步。
  • “逐个候选写支持与反对”可能只是让模型写出看起来合理的话，不一定真的更准；这就是为什么要人工抽查翻转样本。
  • GPT 没有音轨，声音类的对比只能依据字幕和视觉。
  • 样本很少（117 条），而且这块本来就是最难的样本，噪声大。
  • 如果没有提升：说明不一致分支的信息确实有限，最合理的结论是用 Direct 兜底，不再投入这块，转去做新样本评估或一致分支。

六、暂不做的方案（记录，非本次范围）

  • 抽取分歧论断 → 逐个论断盲核对 → 裁判（上一版 v5）：约 350–600 次调用，每步都没有我们数据的支持；等这一版的结果出来再决定要不要加。
  • 倡导者加裁判、匿名化或反从众的辩论变体：辩论本身没有新信息，预期收益有限。
  • Conformal 预测集：候选覆盖已经够高，瓶颈不在覆盖。
  • 用训练集做经验记忆、跨模型辩手：成本高，且训练集是筛选过的，放到后面。
