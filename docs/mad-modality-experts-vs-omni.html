按模态分工的多专家（辩论 / 投票 / 编排）会不会不如全模态直接回答？

2026-11-04。检索 arXiv、ACL Anthology、会议论文页与搜索摘要，读了约 9 篇的全文或关键章节，另有数篇只读摘要（抓取工具按字数截断，未读部分见文末）。只读文献，未运行代码、未调用模型。数字以抓取到的原文为准，我没有逐一核对原表。

先说结论
  1. 没有找到一篇论文，直接做“每个专家只负责一个模态 → 辩论或投票 → 与单个全模态模型直接回答对比”，并在情感任务上给出这一对比。最接近的 Listen（Pattern Recognition 2026）用的是两个跨模态 agent，全文在付费页面，我没读到数字。
  2. 但有间接证据表明这种现象存在，最强的一条来自 OmniGAIA（arXiv 2602.22897 §5.5）：把音频或视觉感知拆成“工具/专家”，对强模型 Gemini-3-Flash 反而更差（原生 51.7，只把视觉工具化 43.3，音频和视觉都工具化 46.4），而且调用更多。作者的建议是：强 agent 默认用原生多模态输入。
  3. “多专家编排赢过全模态模型”的结论，几乎都是和较弱的全模态基线比的（Agent-Omni 对 Qwen2.5-Omni），而且专家模型本身比基线强；在强基线或某些基准上仍然输（OmniInstruct 77.50 对 81.06）。
  4. 多模态任务上的辩论 / 投票对比单次回答，普遍是“小幅、不稳定”：M3MAD-Bench 里 GPT-4o-mini 上辩论 −0.6、DMAD +0.1；MV-Debate 的表里同模型多 agent 在多处低于单模型（作者没有讨论）。
  5. 没有一篇论文复现了 Debate or Vote 那样的鞅分析，且该分析的假设（同质 agent）不适用于“各看一个模态”的异质专家。这是我的判断，不是文献结论。

1. 最接近的“按模态分工”工作

论文怎么分工有没有对照单个全模态模型结果与我读到的限制
Listen（Pattern Recognition，pii S0031320326004115，2026）两个 agent：Text-Audio 与 Video-Audio；独立分析 → 交叉质询 → 共识综合摘要只说明动机是单体 MLLM 在模态不同步、可解释性上的局限；我只读到摘要与搜索摘要，没有对比数字作者宣称显式讨论能解决模态冲突；无法核实，不能当作证据。数据集 CH-SIMS / CMU-MOSI 等情感回归 / 情感倾向任务，不是我们的离散情绪
AffectAgent（arXiv 2604.12735）三个 agent（规划、证据过滤、情绪生成），按角色分，不按模态分，共享一个 MLLM对比同一骨干加 / 不加 AffectAgent：Video-LLaMA2 35.99→42.74，AffectGPT 74.77→76.78需要训练（SFT + MAPPO，检索库来自 MER2025 训练集），不是免训练；没有“多 agent vs 同骨干单 agent”的对照；与我们的约束不符
MiAgent（Springer，情感支持对话）视频 / 音频 / 文本三个 agent（Video-LLaMA、Qwen-Audio、LLaMA 3）只有“去掉某模态 agent”的消融，我没读到全文协作推理，不是辩论；没有单个全模态模型对照
Project Riley（arXiv 2505.20521）五个情绪 agent，视觉 LLM 描述图像，文本 LLM 跑 agent，推理模型投票没有任何基线只有 17 人 Likert 用户调研；不能回答我们的问题
MER 2024 基线（arXiv 2404.17113）音频 / 视频 / 音视频 LLM 各自按“情绪专家”提示，再融合融合不是辩论仅作背景

2. 编排型：模态专家 + 主控 agent vs 单个全模态模型

Agent-Omni（arXiv 2511.02834，免训练）

主控 agent（Claude 3.7 Sonnet）循环四步，调用模态专家：文本 DeepSeek-R1，图像和视频 Claude 3.7 Sonnet，音频 Qwen2.5-Omni；专家只看自己模态的输入，看不到原始问题；循环上限 3 次。

  • 强模型：原生最好且调用最少；作者认为工具化“没有精度与成本上的收益”。
  • 弱模型：工具能补低层信号，在简单和中等题上有帮助，但在困难题上一致变差（Qwen-3-Omni 困难题 9.0 → 3.9 / 5.1 / 7.7）；作者的说法是工具输出“不能替代原生的跨模态整合”。
  • 作者的建议：能力强的 agent 默认用原生感知，工具化感知留给弱模型或缺失模态的场景。
  • 局限：这是智能体长程问答，不是情感分类；“工具”是调用别的模型读媒体，不是辩论。Omni-Decision（arXiv 2607.11433）在附录 D 转引了同一张表。

Chain of Modality（arXiv 2604.14520）

比较固定组织方式：单模态、Parallel（各模态分别推理再聚合）、Sequential、Interleaved。关键点：Parallel 只在音视频冲突时更可靠，而且是按真值答案的平均对数概率衡量（Parallel −0.67，联合 −0.86，单音频 −1.05，单视频 −0.74），差距很小；准确率并不明确偏向 Parallel。时序推理上联合的交错方式反而更好（Interleaved 48.5 对 Sequential 45.4）。作者的结论是“没有单一组织方式处处占优”。需要 logprob，且增益在专挑的“对拓扑敏感”子集上。

Training-Free MLLM Orchestration（arXiv 2508.10016，ICML 2026）

只读到摘要：宣称“强表现”“低编排开销”，我拿到的内容里没有与单个全模态模型的具体数字对比，所以不下结论（搜索摘要说它“接近”原生训练的全模态模型，我没有核实）。

Omni-Decision（arXiv 2607.11433）：一个反例

证据账本规划的全模态 agent 在 OmniGAIA 上 81.39，对 Gemini-3.1-Pro 的 79.44，成本约 1.2 美元对 2.8 美元；论文自己承认账本质量受限于感知工具的文字输出，且 40.3% 的失败来自媒体感知。差距只有约 1.95 个点，单次运行，且它依赖规划器和评审器，不是简单的辩论或投票。可作为“编排可以略超强单模型”的存在性证据，但要带着这些限制读。

3. 辩论 / 投票：多模态任务上对比单次回答

  • 基线选择会夸大收益：CoT 在 PathVQA 上远弱于 IO（Qwen 26.0 对 45.4），只和 CoT 比会虚高。
  • 失败归因里“集体错觉”占 65%、选择失败 17%（100 条抽样，未按模态拆分）；论文没有分析“各 agent 重复同一个视觉误读”，所以不能用它支持“辩论会放大共同的感知错误”。

MV-Debate（arXiv 2508.05557，免训练，文本 + 图像的有害内容检测）

四个“视角”agent（表层分析、深度推理、模态对比、社会语境），每个都同时看文本和图像，按视角而不是按模态分。基线表里（Acc / F1 的三数据集平均）：

  • 单模型零样本：GPT-4o 75.7 / 74.2，Gemini-Flash-2.5 75.9 / 73.4，Claude-4-Sonnet 77.1 / 74.3。
  • 已有辩论：MAD 74.2 / 71.3，DebUnc 74.0 / 68.3，DMAD 76.9 / 74.4，ChatEval 77.0 / 76.6——MAD 的平均准确率低于上述三个单模型。
  • MV-Debate 同模型（同质）多 agent 在若干列低于单模型：Claude-4 的 GossipCop F1 69.2 对单模型 73.9；InternVL3 的 GossipCop F1 62.3 对 68.7、MMSD F1 75.5 对 78.6。作者没有讨论这些。
  • 自家方法的优势主要来自异构模型 + 裁判 / 反思：异构闭源 84.9 / 78.0。但裁判 Claude-4-Sonnet 同时又是单模型基线，存在混杂；各方法差距常只有 1–3 个点，每数据集 500 条、单个种子、无方差。

“LLM 评委的多智能体辩论”（arXiv 2510.12697）

视觉任务 Table 1（单模型 / 多数投票 SoM / 辩论，7 个 agent）：Qwen-2.5-VL-7B 在 MLLM-Judge 为 60.43 / 60.88 / 60.38，JudgeAnything 为 67.88 / 68.42 / 67.67——辩论不优于单模型；Gemini-2.0-Flash 上辩论分别 69.25 与 85.71，高于单模型 67.50 与 81.63。标准误约 3 个点，所以这些差距都在误差范围内。作者的解释是：高共识的简单任务上 SoM 与辩论相当。它的 Theorem 4.2 比较的是辩论与初始多数投票，不是与单模型。

4. 间接机制证据：把模态转成文字再推理会丢信息吗

  • 多模态情感识别综述（arXiv 2509.24322）：基于 LLM 的流水线把编码器输出投到文本空间再处理，常造成信息损失并阻碍跨模态交互；端到端 MLLM 能保留模态特有信息（综述性说法，非受控实验）。
  • LISTEN 基准（arXiv 2510.10444）：音频 LLM 在只有声学或副语言线索时性能大幅下降，接近随机。
  • 端到端情感计算基准（arXiv 2508.02429）：生成的描述有时没有增益，还会因冗余轻微干扰判断。
  • EmoMM（arXiv 2605.01024）：单个 MLLM 在模态冲突下出现“视频贡献坍缩”，会忽略视频证据——这说明全模态直接回答也有自己的模态偏置，不是只有优点。

这些都是间接证据：没有一个在情感任务上把“文字化的模态专家再聚合”与“全模态直接回答”在同一模型、同一数据上受控比较。

5. 与 Debate or Vote 的关系

  • 没有论文在多模态专家场景里复现 Debate or Vote 的鞅分析。M3MAD-Bench 与 MV-Debate 的现象（辩论相对单次回答小幅、不稳定，部分低于）在现象层面类似该文“多数投票解释了大部分收益”，但它们的 agent 是同质的，每个都看全部输入。
  • 按模态分工的专家与鞅模型的前提不同。鞅分析需要同质、全连接、互相可见信念；而模态专家掌握不同的私有信息，更像 2609.38324 的 HiddenBench（隐藏档案）场景，那里讨论的收益取决于是否压制异议，而不是辩论本身是鞅。这是我的推断，没有论文直接这样说。

6. 对我们的含义

  • 我们的 F6 观察（不一致分支 Direct 38/62 与 26/55，优于 v4 辩论 26/62 与 19/55）在文献里没有找到完全对应的报道；最强的旁证是 OmniGAIA：强模型原生输入优于把感知拆成工具。这支持把 Direct 作为基线、专家只作辅助的方向，但并不等于文献证明了我们的结果。
  • Agent-Omni、AffectAgent 这类“编排赢过全模态”的论文，基线较弱，或需要训练，所以不能当作“我们应该继续做专家辩论”的依据。
  • Omni-Decision 显示编排在强基线上也可能略胜，但靠的是证据账本、规划器和评审器，并且依赖感知工具的文字输出质量；它是“如何在不低于 Direct 的前提下让专家有用”的一个线索，不是现成答案。
  • EmoMM 提醒：Direct 自己也会忽略视频，所以“Direct 好”不等于“Direct 处处好”；这与我们 F7 里 Direct 在不同数据集 / 模型上的不稳定相符。

7. 局限

  • 覆盖不全：我检索了英文来源和少数中文关键词，可能漏掉未被检索到的论文；Listen 的正文与表格是付费页面，没有读到。
  • Training-Free MLLM Orchestration、MiAgent、MERMAID、Georgia Tech 学位论文（ScienceQA，宣称辩论显著优于单模型，非正式论文）只读到摘要或页面，没有数字，所以没有放入结论。
  • OmniGAIA、Agent-Omni 是智能体问答，不是离散情绪分类；MV-Debate、M3MAD 是图文任务，没有音频；全部为单次点估计、多数无方差。
  • 数字来自抓取工具对原文的提取，没有逐一对照原表；OmniGAIA 的表和 Omni-Decision 的转引数字一致，其余未交叉核对。
