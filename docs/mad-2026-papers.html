③ 一个坏消息EMNLP 2026 的 Selection Effect 在情绪分类上得到与我们一致的现象：升级到 LLM 的是难样本，模型再大也不改善。“辩论分支≈随机”可能是结构性的，不只是提示词问题。

三、可以先做的事（均为假设，未运行；是否执行请你决定）

  1. 零成本只读分析：用已保存的 v4 辩论记录计算 Identity Bias 论文里的 Conformity / Obstinacy（少数派改投多数的概率 vs 坚持自己的概率），并按 Free-MAD 的方式事后算“轨迹得分”，看能否在不一致分支上选得比 v4 更准。无新增模型调用。
  2. 试用非投票聚合：把三位专家的推理交给 AgentAuditor 的 prompt-only 路径，只处理不一致分支（400 条里 62 / 55 条）。需要新的模型调用，需你授权；结果属于开发集复用，不能当泛化证据。
  3. 候选集换成预测集：参照 Conformal Social Choice，用校准集估计阈值，得到带覆盖保证的候选集，取代 F1 的人工“易混淆标签”。注意训练集由模型正确性筛选，校准会有偏。
这些只是读文献后的想法。F6 的结论是辩论分支约等于随机，文献（尤其 Selection Effect）提示它可能是结构性的，所以第 1 条先验证“是否还有可选得更准的信号”比直接改流水线更稳妥。

五、方法与局限

  • 文献来自 ACL Anthology 官方元数据（acl-org/acl-anthology 的 2026.acl / 2026.emnlp / 2026.findings XML），不含 EACL；按标题与摘要关键词筛选（debate、multi-agent、deliberation、council、consensus 等），摘要里没出现这些词的相关论文会被漏掉。

  • “未找到代码”只表示论文正文、arXiv 摘要和按名称的 GitHub 搜索都没有，不排除作者之后发布。
  • 各论文的结论取自摘要和 README，数字未逐篇回到实验表核对；引用前请读原文。
  • 脚本：scripts/lit2026/（检索、链接提取、仓库核验）、scripts/build_mad2026_survey.py；核验数据：metrics/mad2026_repo_checks.json。
