0. 先弄懂“鞅”：一个公平赌局

你有 10 元，每轮抛一枚公平硬币：正面 +1 元，反面 −1 元。设 Mt 是第 t 轮后的钱数，则

𝔼[Mt+1∣Mt]=12(Mt+1)+12(Mt−1)=Mt.

“已知现在，下一步的期望等于现在”就是鞅。一般地，设 ℱt−1 是到 t−1 步为止的全部历史，则

鞅： 𝔼[Xt∣ℱt−1]=Xt−1,次鞅： 𝔼[Xt∣ℱt−1]≥Xt−1.

如果硬币偏向正面（正面概率 0.6），则 𝔼[Mt+1∣Mt]=0.6(Mt+1)+0.4(Mt−1)=Mt+0.2，这是次鞅，有向上的漂移。

要点：鞅的值会上下波动，只是没有可预测的方向。取总期望，有 𝔼[XT]=X0：玩多少轮，期望收益都是 0。

1. 辩论为什么是鞅：2508.17536《Debate or Vote》（NeurIPS 2025 Spotlight）

模型

  • K 个选项，选项 1 正确。agent i 在第 t 轮有 Dirichlet 参数 αi,t=(αi,t(1),…,αi,t(K))。
  • 它先抽信念 θ~Dir(α)，再按 θ 抽回答。选项 k 被回答的边际概率为 α(k)/∑jα(j)。
  • agent 对正确答案的信念：pi,t=αi,t(1)/∑kαi,t(k)。
  • 辩论一轮就是把邻居回答的计数 𝐜i,t 加进参数（Dirichlet 与类别分布共轭）：αi,t=αi,t−1+𝐜i,t。

定理 2（鞅）

若第 t−1 轮邻居的平均信念等于 agent 自己的信念，

1|𝒩(i)|∑j∈𝒩(i)pj,t−1=pi,t−1,

则

𝔼[pi,t∣历史]=pi,t−1.

论文说明该结论在同质且全连接、完全隔离、孤立的同质小团三种情形下成立（Appendix D.3.1 Prop.1）；附录对异质 agent 的推广在我读到的文本之外。

我的推导（帮助理解，不是原文）

设有 n 个邻居，每个邻居以概率 pj 给出正确回答，St−1=∑kαi,t−1(k)。则新增正确计数的期望为 ∑jpj，总计数增加 n：

𝔼[pi,t∣历史]=αi,t−1(1)+∑jpjSt−1+n.

当邻居平均信念等于自己的信念（∑jpj=npi,t−1，且 αi,t−1(1)=pi,t−1St−1）时，分子 =pi,t−1(St−1+n)，于是期望就是 pi,t−1。如果邻居平均比自己更相信正确答案，分子变大，就变成次鞅。

定理 1（多数投票的“放大效应”）

设正确选项与亚军的平均概率差为 Δ=θ¯1−θ¯2。若 N>K/Δ2，则 N 个 agent 做多数投票成功的概率满足

P(ymv=1)≥1−exp(−N(ΔK−1N)2).

二分类且 p0>1/2 时（Appendix C，Hoeffding）：P(X¯>1/2)≥1−exp(−2N(p0−1/2)2)。

2. 置信加权与多样性：2601.19921《Demystifying Multi-Agent Debate》

理论（沿用 Dirichlet 模型，Appendix D）

无偏辩论仍是鞅：𝔼[pi,t∣ℱt−1]=pi,t−1（Eq.14）。

多样化初始化（Prop.1 / Thm.2）：令 S 为初始池里不同的“有信息的假设”个数。若 P(正确∣S=s) 随 s 不减，且多样化初始化在一阶随机占优意义上优于随机采样，则

P(correct∣diverse init)≥P(correct∣random init).

论文的示例形式是 1−(1−p)s。动力学不变，只是起点变好。

置信加权（Thm.1，次鞅）：用置信度 wj 对邻居投票加权，

c~(k)=∑jwj1{yj=k},αt=αt−1+c~t,pi,t=αt−1(1)+Δ(1)St−1+Δ.

Lemma 1 说明 pi,t 是 pi,t−1 与“置信加权后正确质量占比”的凸组合。在 Assumption 1（置信度与正确性正相关：ρj≥pj，且在正概率集合上严格）下，

𝔼[pi,t∣ℱt−1]≥pi,t−1.

条件：同质、全连接，且校准后置信度与正确性正相关。

方法与是否黑盒

  • 多样化初始化：采样 Ncand=10 个候选，贪心选出 5 个使答案种类最多（免训练，但多采样）。
  • 置信调制辩论：agent 输出 0–10 的口头置信度，并用 GRPO + LoRA（rank 64）训练表达与使用置信度。表达奖励 rconf=λRmax[zlogw+(1−z)log(1−w)]，总奖励 rtotal=λ1z+λ2rconf。需要训练，不是免训练方法。

3. 分歧会被压成错误共识：2609.38324（2026-09）

模型（均场）

N 个 agent，二元私人信念 z 与公开陈述 y（1 表示正确），每个 agent 看到 q 个随机邻居（q≥3 才出现阈值）。每个人初始正确的概率为 p。更新规则：

  • 可见多数与自己的信念一致：照说自己的信念。
  • 不一致：以概率 c 压制异议，说多数的答案，再以概率 a 内化它；以概率 1−c 说出自己的信念，并以概率 ρd（d 为可见异议比例）重新考虑，重新考虑后正确的概率为 r。

定义净纠正率

γ≡ρ(2r−1).

临界条件（Section 2.2，Appendix A.1）

在全错状态 (Z,Y)=(0,0) 附近，多数正确项是 O(Y2)，系统线性化为 Zt+1=Λ(c)Zt，其中

Λ(c)=1−ca+(1−c)γ.

正确的少数派增长，当且仅当 (1−c)γ>ca，令 Λ=1 得临界压制率（Eq.6）：

c*=γγ+a
  • a→0 时 c*→1：只压制、不内化，不会锁定错误共识。
  • r>1/2（即 γ>0）时，全正确状态对任意 c 都稳定。
  • c>c* 时两个稳定态共存，由 p 决定去向；相变点 p*(c) 用数值求得，略早于 c*。“恢复区间”是 p*(c)<p<1/2。
性质：这是线性化得到的一阶局部阈值，不是全局定理；作者承认“重新考虑与可见异议成正比”这一前提无法从日志识别，私人答案只是操作性测量。附录 A.2 用数值验证了闭式与模拟一致。

什么能提高讨论的增益（Section 4，Appendix C.1）

  • 提示“如实回答”压低 c；强调“团队凝聚”的提示抬高 c，增益变小。
  • 关闭推理：对压制率没有稳定影响，但降低内化率 a，于是 γ 与 c* 上升，增益上升。
  • 强制 c=1 几乎消除增益；强制 c=0 只对 gpt-4o-mini 提高了增益。
  • 增益的比较基线是同一聚合规则在第 0 轮（独立投票）的准确率，在 HiddenBench（65 题）、hidden profile（120 题）、MuSiQue、MedEInst 上评估。具体增益数字在原文图 2d–g，抽取文本里没有。

4. 博弈论视角：2510.20963《When and Why Does MAD Fail》

设两位辩手 A、B 持有相反答案，裁判 J 看原始回答 X0 与辩论消息 M。辩论有用当且仅当

I(Y;M∣X0)>0.
协议建模结论
竞争式 CopMAD零和 + 廉价谈话（Prop.2.4）均衡为“胡说”，风险 Vcop=R0，等于不辩论的贝叶斯风险
共识式 CosMAD辩手共享“达成一致”的效用（Prop.2.6）只保留一致部分会丢信息：R(X0,Φ∩(M))≥R(X0,M)，分歧含信息时严格
协作式 ColMAD共享“求真”效用，非零和（Prop.2.8）Vcol≤R(X0)，当 I(Y;Me∣X0)>0 时严格
Cor.2.9：Vcol≤Vcos≤R(X0)=Vcop.
注意：Prop.2.8 的界主要来自“裁判可以忽略记录”，所以保证的是不比单 agent 差，不保证更好；是否有增益取决于消息的实际信息量。

5. 救回与带偏的拆分：2606.02866《When Helping Hurts》（2026-06）

对一个条目：pg 是生成器本来就对的概率，pc 是批评者能识别出错误的概率，pr 是修正后变对的概率。辩论对该条目有益，当且仅当“救回”大于“带偏”（Eq.1）：

(1−pg)pcpr>pg(1−pc).

等价的赔率形式：

pc1−pcpr>pg1−pg.

任务级近似（Eq.2）：

ΔPerf(T)≈kα[⋯](1−ρβ),

其中 k 为条目数，α 为批评被采纳的比例，ρ 为输出依赖度，β 为级联严重度（报告 AutoDCWorkflow 约 1.3，MaTElDa 约 0）。

性质：这是推出来的判据，不是严格定理，完整推导在附录 L（我没读到）；pr 按答案空间类型粗取约 1.0 / 0.5 / 0.2，pc 常用代理量。

6. 经验分析：2605.09618《Statistical Scouting》（2026-05）

在同一个 960 token 上限下比较三种协议：贪心（直接回答）、三次采样投票、两 agent 批评-修正辩论；模型为 Llama 3.1 8B 与 Ministral 3 8B，任务为 MuSiQue 与 GSM8K。没有形式化定理，主要结果：

  • 让一个“每条样本选对协议”的 oracle：在 MuSiQue 上比最好的固定协议高 +14.0 与 +13.7 pp（给出路由的上限）。
  • 投票熵阈值控制器（三条链全不一致，H>1，才升级为辩论）：
模型最好固定协议阈值控制器Δ（pp）95% CI（配对 bootstrap）
Llama 3.1 8B43.745.0+1.3[−3.7, +5.3]
Ministral 3 8B49.050.7+1.7[−1.7, +4.0]
  • 联合检验：固定效应 meta 分析 +1.6 pp（p=0.125），Fisher 合并 p=0.22，不显著；学习型控制器没有超过阈值。
  • 投票熵只能预测辩论安全（H 高时反噬少），不能预测辩论有用（帮助率各层大致持平）。47 个辩论有益样本中，31 个（66%）属于 H≤1，其中全票一致且错误 17 个（约 36%）。
  • “一次性 CHANGE/KEEP 探针”在 127/127 个全票一致样本上都翻转，与辩论是否有益的互信息为零（作者提示可能是提示遵从的假象）。
  • 作者的限制：两个约 8B 模型、两类 QA、N=300、只控制 token 上限而非实际消耗（辩论实际消耗更多）、所有个别 CI 都跨 0。
