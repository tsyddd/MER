T5　v4 流程与相对 v3 的变化

环节相对 v3说明
组织文本、三位专家的四条 rubric、情绪轮、易混边界不变验证集的组织文本直接复用同模型已保存输出；训练集按相同提示词新生成。
Round 0 专家改默认 1 个答案；真正两难时可再给 1 个备选（alt_answer / alt_open_emotion / uncertainty_reason）。
反思（新增，每条样本）新增只看原媒体与自己的 Round 0 输出；核对证据、找最强反证、检查映射；仍允许 1–2 个答案。
路由（代码）新增三位答案集合的交集恰好 1 个标签 → 直接输出；否则辩论。
辩论（≤2 轮）新增读另两位反思后的完整输出；改自己需引用对方证据（adopted_evidence），劝对方需带可定位证据；答案限定在候选并集内。
汇总器小改只在辩论后仍不一致时调用；evidence_refs 汇集三位专家任一阶段的证据（角色:阶段:E编号）。
